# qa-nutrilife-audit
Audit de la qualité de NutriLife, une application web de planification des repas et de nutrition. Ce projet porte sur des tests fonctionnels ciblés concernant l'inscription, le parcours d'accueil, la planification des repas, la génération de listes de courses, la navigation ainsi que les éventuels problèmes d'ergonomie ou de fonctionnalité.
